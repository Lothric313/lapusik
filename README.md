# Лапусик

Демонстрационный сайт зоосалона «Лапусик» в Москве.

Сайт: https://lothric313.github.io/lapusik/

## Запуск и публикация

Статический сайт без сборки и зависимостей. Для локального просмотра откройте index.html в браузере. GitHub Pages публикует корень ветки main; файл .nojekyll отключает обработку Jekyll. Изменения основной ветки автоматически обновляют сайт.

## Контакты и оформление

Адрес: Москва, центр. Встроенная карта и маршрут показывают координаты 55.755814, 37.617635 без привязки к организации. Все кнопки звонка и записи используют телефонную заглушку +7 (000) 000-00-00.

Рейтинг 4,9 и 124 оценки — элементы демонстрационного макета; переходы на отзывы реального салона отсутствуют. В трёх диалогах карточек услуг показаны 21 позиция демонстрационного прайса.

Иллюстрации питомцев созданы ImageGen для оформления. Шрифт Manrope подключён локально; лицензия находится в assets/fonts/OFL.txt. Встроенная карта требует интернет. Анимации учитывают настройку уменьшения движения.
