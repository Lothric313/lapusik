# Лапусик

Одностраничный демонстрационный сайт зоосалона «Лапусик» в Москве. Откройте index.html в браузере или запустите node preview-server.cjs и перейдите на http://127.0.0.1:4173/. Сборка и установка зависимостей не нужны.

## Контакты и карта

Название сохранено. Адрес во всех блоках: «Москва, центр». Встроенные Яндекс Карты, ссылка на карту и маршрут используют координаты центра Москвы: 55.755814, 37.617635. Карточка конкретной организации к карте не привязана.

Телефон +7 (000) 000-00-00 — демонстрационная заглушка, а не действующий номер для записи. Все ссылки tel используют этот номер; перед публикацией его нужно заменить на рабочий.

Рейтинг 4,9 и 124 оценки оставлены как элементы макета. Это не подтверждённые оценки московского салона. Рейтинг и плашки оценок больше не являются ссылками. Ссылки на карточку и отзывы исходной организации удалены. Награда Яндекс Карт заменена нейтральной плашкой «Бережный уход».

## Услуги и оформление

В трёх диалогах карточек услуг показаны 21 позиция демонстрационного прайса. Минимальные цены в карточках соответствуют спискам внутри диалогов. Кнопки записи используют телефонную заглушку.

Сохранены зелёная и голубая палитра, логотип, структура, изображения питомцев и анимации. Изображения созданы ImageGen для оформления; это не фотографии клиентов салона. Промпты находятся в assets/lapusik-image-prompts.txt и assets/cavalier-prompt.txt. Неиспользуемые изображения сохранены для восстановления.

Шрифт Manrope подключён локально из assets/fonts/Manrope-Variable.ttf. Лицензия находится в assets/fonts/OFL.txt.

Для пользователей с настройкой уменьшения движения анимации отключены. Встроенная карта требует интернет. Изменения сохранены локально; публикация на хостинг не выполнялась.

## GitHub Pages

Сайт готов к размещению как статические файлы без сборки. Файл .nojekyll отключает обработку Jekyll. В настройках репозитория GitHub Pages нужно выбрать публикацию из корня основной ветки. Ссылки на CSS, JavaScript и изображения относительные, поэтому сайт работает и по адресу репозитория.

Локальные предпросмотры, сервер разработки и неиспользуемые иллюстрации исключены из Git через .gitignore.
